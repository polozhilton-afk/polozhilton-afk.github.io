Zavod

Личный контент-конвейер для производства видео-разборов фильмов.

Приложение для собственного использования: автоматизирует подготовку, озвучку и упаковку видеороликов из исходных фильмов.

Интеграция с Google Drive используется для хранения собственных рабочих материалов (видеофайлов) в личном хранилище владельца.
